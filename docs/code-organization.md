# 代码组织与职责

按能力的所有者、变化原因和生命周期组织代码。移植使用原实现作为起点，可在调用合同和行为可对照的前提下做局部重构。

## 入口与实现

| 位置 | 职责 |
| --- | --- |
| `packages/editor/src` | 编辑器实例负责挂载和释放，Range 与 Selection 负责所属编辑区的选区，命令定义负责编辑操作 |
| `packages/editor-element/src` | 自定义元素负责注册、连接和断开、属性映射、事件转发 |
| `packages/charts/src` | 图表实例负责装配、图层、调度和清理，系列、比例尺、图形和提示框各自持有绘制与交互规则 |
| `packages/kline/src` | K 线实例组织行情、画布和交互生命周期。Layout 管可见区间与图表区域，Chart 管比例尺与指标，画笔负责绘制 |
| `packages/highlight/src` | 语言入口按依赖顺序登记规则，分词模块负责词法匹配，渲染模块负责 HTML 转换和 DOM 更新 |
| `packages/async` | AMD 加载器与旧 Promise 分别有可直接加载的 ES5 入口，模块缓存属于加载器实例 |
| `packages/declare` | 独立的 ES5 原型类工厂，调用方持有和组合构造器 |
| `packages/animation/src` | 场景与帧的调度及播放状态，调用方负责绘制 |
| `packages/scroll-view/src` | 几何计算与 DOM 行为分开，原生视口持有滚动位置，调用方负责结构和样式 |
| `packages/tools/src` | 一个公开函数对应一个模块，分类入口汇总函数，根入口汇总分类 |
| `packages/simple-mvvm/src` | Observer 持有字段订阅，ViewModel 选择渲染路径并管理挂载，VElement 持有节点描述并复用 diff 与 patch |
| `packages/dom/src` | 独立交付历史 Elements 和 jQuery 风格的插件接口，以原生 DOM 实现集合、事件和效果 |

包间依赖通过清单和公开入口声明。编辑器保持普通 DOM 接入能力，Web Component 直接使用该能力。图表独立持有 Canvas 绘制模块。工具栏、弹窗、状态栏和视觉样式由编辑器的调用方组织。

## 原生 API 与局部复用

各业务包直接使用原生元素类型、`querySelector`、`classList`、事件、Selection、Range 和 Canvas。封装集中在有语义的组合操作，例如选区恢复、插入内容后的光标处理、同一生命周期内的监听清理。需要 jQuery 风格接口的外部插件可使用独立的 `@sugars/dom`。

保留职责明确的局部 helper，存在实际通用消费场景后再评估共享边界。通用数据操作可使用 `lodash-es` 等现成依赖，替换时先对照回调参数、接收者和数组合并行为。DOM 操作和绘制规则由对应模块持有。

## 集中登记与按职责拆分

同类编辑命令、图表系列等稳定可枚举的能力优先集中登记。让同一声明驱动类型约束、匹配及实际分发，新增项同时核对实现、公开合同和用例。选区处理、坐标换算和绘制循环按算法本身清晰表达。

可以合并边界相同且联动修改的文件。评估模块拆分时看职责、复用与阅读路径。涉及历史行为的合并应有对应样例可验证，例如区间柱和单值柱、item 和 axis tooltip、高层图形和基础图层。

## 源码注释

Sugars 的源码说明统一用中文。参考 Jangts 采用的代码风格与可读性条目 C01–C05，按仓库现有代码风格维护注释与实现。

- 文件头写明现行包、模块职责、在调用链中的位置及主要导出或登记项。只有一个公开函数的工具模块可直接用该函数的文档注释承担这项说明。
- 公开函数和方法用 JSDoc 逐项说明参数、返回值及适用的异常。导出的类型注明重要字段的单位、取值约束、缺省行为或所有权。
- 实现注释解释算法取舍、兼容边界和不容易看出的运行顺序。保留移植来源，名称容易误解的旧接口要写清实际行为。
- 贴着相关分支、规则或常量写原因。高亮规则应交代容易误改的匹配优先级、定界符、上下文或嵌套关系。
- 作者、来源、许可声明及原始示例保留。重复的旧项目横幅和已失效的命名空间集中记在迁移或来源文档中。
- 注释随实现同步。简单赋值、转发和类型已表达清楚的部分可以省略说明。

## 素材和产物

运行素材归实际消费它的包。编辑器默认 GIF 的入口清单与文件、构建复制和发布包体一并检查。保存原有文件与来源，替换时记录授权和引用变化。临时检查材料与正式运行素材分开存放，生成产物由其源码或配置更新。
