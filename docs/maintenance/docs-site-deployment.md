# 双语文档站部署

- 公开入口为 [Sugars 文档站](https://sugars-docs.pages.jangts.cafe/)。该站使用武汉自建 Jangts Pages 的通配域名与证书。
- 服务器站点目录为 `/opt/stacks/nginx-proxy-manager/data/pages/sugars-docs/`。从仓库根目录按[文档站说明](../../apps/docs/README.md)构建和检查，发布 `apps/docs/dist/` 中的静态产物。

## 2026-11-27 首次发布

- 沿用 RESTModel 文档站的 Pages 发布流程。通过 SCP 上传静态产物，远端核对归档和 310 个文件的 SHA-256 后安装到 Sugars 站点目录。
- 从公网 HTTPS 逐一下载并校验 310 个文件，包含中英文页面、实际 JS、CSS 和站点地图。访问缺失路径返回 HTTP 404。
- 使用浏览器检查了首页语言选择、保留查询参数和锚点的语言切换、中英文搜索与移动端语言切换。

## 2026-11-27 标志更新

- 导航使用单色图标与标准字的横向组合，favicon 使用独立单色图标。中英文首页加载立体原稿，中文和英文首页的标题按可用宽度平衡换行。
- 远端发布前核对了归档及 314 个静态文件的 SHA-256。发布后经公网 HTTPS 逐文件复核，缺失路径返回 HTTP 404。
- 浏览器核对了中英文首页在桌面和移动端、浅色和深色下的显示，确认三个线上标志资源与仓库中的对应文件一致。
- 随后将两版组合的标准字等比缩小 18%，保持图标与字形主体居中。调整后的单色组合已重新发布到导航，公网复核 314 个静态文件并再次通过桌面和移动端浏览器检查。
- 正式组合改用图标充当首字母 `S`，收紧图标和 `u` 的字距，同步保留单色 SVG 和立体 PNG。新版单色组合已用于导航，页签及首页仍加载原有图标。公网逐一核对 314 个文件，并用浏览器验证中英文页面的桌面和移动端显示。
- 将导航组合标志的高度从 24 像素调整为 30 像素。线上核对 1366、390 和 320 像素视口的标志尺寸与导航间距，并复核 314 个静态文件。
