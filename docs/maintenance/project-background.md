# 迁移背景与共识

本记录依据 TangramJS 与 Interblocks 的讨论、源码检查、sugars 工作区和首次移植的验证整理。日常使用和维护从 [项目文档](../README.md) 进入。

## 项目由来

Interblocks 是较早的一套前端框架，TangramJS 是后续整理。它们保留了当年对传统 JavaScript 机制的学习和实践，尤其是模块加载、类工厂、Observer、ViewModel 和虚拟 DOM。这部分历史有其独立价值，因此两套原框架原样保存。演进关系来自开发者说明和源码相似性，具体模块的完成时间未逐一核定。

sugars 的起点是从 TangramJS 中整理可独立使用的富文本和图表。移植在副本上进行，保留代码来源和原框架的完整性。范围限于这两套前端框架的历史和本次提取的工具。JangRAM、JangRAM P、BackStage 及相关站点业务另有各自的讨论与记录。

已检查的源包标记为 `@jangts/tangram.js` 2.9.1，核心内部版本字符串和包版本不一致。原目录包含整合代码及来源尚待确认的素材，现存源码也有缺失依赖。因此源码规模、版本号和附带许可证文本都不能单独证明历史原件完整可运行或每个模块均为同一作者原创。

## 已确认的维护方向

| 共识 | 在 sugars 中的含义 |
| --- | --- |
| 整理已有作品 | 以原 SimpleEditor 和 Charts 为基础。允许优化和适度重构，接口设计、主要用法和有效行为以原实现为基线 |
| 全面改为 TypeScript 与 ESM | 以标准模块依赖取代原模块加载、全局命名空间和类工厂。通用数据处理可用成熟依赖 |
| 编辑器以原生 DOM 为基础 | 保留选区、命令、内容读写与相关生命周期。封装限于可复用的组合操作和语法糖 |
| 两种无头编辑器 | `@sugars/editor` 是普通 DOM 可直接使用的包，`@sugars/editor-element` 是直接复用它的标准 Light DOM 元素。工具栏、弹窗和视觉样式由调用方提供 |
| 三包边界 | 两个编辑器包是单向依赖，`@sugars/charts` 独立。两个编辑器均配置公开发布，charts 当前保持私有 |

## 图表的简化尺度

早期曾试写以单 Canvas 和集中渲染函数为主的草稿。它覆盖了五种图的常见绘制，但缺少区间柱、按轴汇总提示、实际 Canvas 分层和命名主题入口。当前移植使用原系列、比例尺、基础图形及提示框为基础，并保持构造和配置用法。

后续优化用具体调用比较，例如单值柱和区间柱、单点提示和跨系列按轴提示、绘制顺序和独立图层。能在同一输入下保持这些行为的局部合并有实际价值。文件数和行数本身无法判定两个实现是否等价。

## 已验证和待核对

首次移植曾在本机 Chrome 验证原生编辑器的选区恢复、撤销、插表、表单同步和默认表情，验证了 Web Component 断开和重连，也验证了五种图表的实际绘制、悬停、数据清空、调整尺寸和销毁。另检查了命名主题、横向区间柱、动画完成与停止。记录对应首次移植，未覆盖全部历史选项或所有浏览器。

两个编辑器的公开发布配置通过构建及 npm 打包清单预检，截至该次检查未上传 npm。历史代码与默认表情的分项许可仍待核实。[移植说明](tangramjs-migration.md)维护源模块映射和已知差异。
