# 代码检查与验收标准

按变更影响选择检查项。构建、合同对照、浏览器行为和发布包体各自提供证据。检查记录写明使用的版本、输入或场景、实际结果和未覆盖范围。

| 编号 | 检查内容 | 适用证据 |
| --- | --- | --- |
| L0 产品与基线 | 变更属于哪个包，原行为或现有合同是什么，哪些变化已经明确 | 原源码、旧调用示例、当前公开入口、迁移对照 |
| L1 接口设计 | 构造入口、参数、默认值、返回和事件与调用一致 | 通过包入口运行的最小用法和受影响的旧用法 |
| L2 组织与复用 | Web Component 复用编辑器，图表与编辑器独立，原生 DOM 封装有具体职责 | 包清单、引用关系、实际分发 |
| L3 类型与行为 | TypeScript 声明、动态输入及空值处理与真实行为一致 | 构建、类型检查、有针对性的调用 |
| L4 状态与生命周期 | 选区、内容、表单同步、元素重连、图表更新和资源清理符合合同 | 受影响的浏览器路径 |
| L5 输入与信任边界 | 外来 HTML、粘贴和插入走正确处理路径，来源和诊断资料按用途保存 | 校验用例、相关依赖与素材清单 |
| L6 渲染与稳健性 | 图表比例尺、图层、像素密度、提示和动画按实际配置工作 | 浏览器绘制和交互证据，性能结论另有量测 |
| L7 交付 | 声明、文档、发布白名单、依赖版本与包体一致 | 打包清单、实际 tarball 以及发布后的 registry 核验 |

## 迁移和重构的验收

同一图形名称可以对应不同承诺。画出柱状图不能覆盖区间柱、组间距和横轴纵轴交换。鼠标出现提示不能覆盖按轴汇总多个系列。相同 `zIndex` 选项也需要区分绘制顺序和具体 Canvas 图层。修改这些规则时，用同一组输入对照原行为或明确的预期。

涉及编辑生命周期时，按需核对工具栏取焦点后的选区恢复、撤销、内容变化事件、表单取值和实例释放。涉及 Web Component 时，按需核对 Light DOM 原有内容、注册、连接、断开与重连。涉及 charts 时，按需核对受影响的系列、比例尺、提示、更新和销毁。仅登记了选项或能力名称无法证明它参与了执行。

行为检查按具体疑问选取最小有效范围。覆盖到的结果可写为通过。未运行或无法复现的事项直接记为未验证。可用命令和现有环境见 [项目检查入口](review-entrypoints.md)。
